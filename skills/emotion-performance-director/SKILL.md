# 剧情人物表演设计

把人物“为什么这样做”转换成观众能观察到的行为差异。身份连续不等于动作重复；同一角色在不同处境中应保留身份，同时改变视线、呼吸、姿态和行动策略。

## 接收条件

开始前取得已批准的场景或镜头版本，并确认人物目标、交流对象、台词原文、镜长、景别、持续进行的现实任务、入镜状态和出镜状态。

若输入仍在探索阶段，输出必须标记 `PERFORMANCE_DRAFT`。不要擅自改动台词、人物关系、剧情结果、道具归属、人物位置、镜头数量或摄影机任务。镜长容不下台词与必要反应时，把冲突退回编剧或镜头规划，而不是偷偷加速或删词。

## 六项观察框架

按镜头需要选择下列要素，不要求每个镜头机械填满：

1. **行动意图**：人物正试图让谁做什么，或阻止什么发生。
2. **公开面具**：人物希望别人看见的状态，例如镇定、客气、无所谓。
3. **有效刺激**：一句话、一个动作、一个物件或一次发现改变了局势。
4. **失控信号**：面具最先在哪个可见通道松动，例如换气、目光停顿或下颌收紧。
5. **主动选择**：人物随后采取的策略，是继续遮掩、反击、退让、求证还是转移。
6. **残留状态**：镜头结束时留下的身体和关系状态，供下一镜继承。

优先选择少量互相支持的信号：眼神目标、呼吸节奏、眼睑与眉间、嘴角与下颌、肩颈张力、握持力度、动作停顿。一次短镜头通常只需要一个主变化和一个余波。

## 现实任务与内在变化并行

先锁住人物在场景中持续执行的现实任务，例如端碗、收拾物品、扶住伤者或守住门口。情绪变化不能无理由让任务消失。只有剧情事件明确打断或改变任务时，才能修改道具、站位或动作目标。

视线必须有对象。短暂回避、失焦和闭眼可以表达压力，但要说明何时重新连接对方、物件或出口。配角收到重要信息时也应出现与其知情范围相符的反应。

## 台词绑定

逐字保留批准台词，说明说给谁、想达到什么效果、重音落在哪个词、哪里需要换气或停顿，以及说完后人物做什么。画内对白要让声音强度、嘴部动作和身体状态属于同一次表演。

生成提示词只写可观察过程，不写人物传记或抽象判断。默认使用自然语言顺序词描述过程；只有剪辑表和动态预演需要精确时间点。

## 交付格式

每个镜头给一张表演卡：

```text
镜头/版本：
人物与交流对象：
行动意图：
持续现实任务：
公开面具：
有效刺激：
失控信号：
主动选择：
台词与声音绑定：
入镜状态 → 残留状态：
允许变化 / 不得变化：
生成降级：
```

用于提示词时只输出表演层，避免重复场景、摄影、材质和平台参数。

## 实际视频诊断

只有观看真实视频后才能给出成片结论。记录文件版本、镜头、时间点、可见证据和最小返修层级，并使用下列标签：

- `PERF-01 STATIC`：承担剧情信息但行为长期没有变化；
- `PERF-02 UNMOTIVATED`：表情或动作没有可见诱因；
- `PERF-03 TASK_DROPPED`：人物无理由丢失持续任务或道具；
- `PERF-04 GAZE_LOST`：视线对象随机漂移；
- `PERF-05 OVERDRIVEN`：多个面部或肢体通道同时过强；
- `PERF-06 CONTINUITY_BREAK`：上一镜残留状态没有被继承；
- `PERF-07 IDENTITY_DAMAGE`：表演过程中五官或身份结构失真。

先减少竞争动作、降低单次变化幅度或拆分镜头，再考虑重新生成。不得在没有诊断的情况下连续重抽。

## 通过条件

- 行为变化由剧情刺激引起；
- 人物目标和现实任务没有被情绪指令覆盖；
- 台词、目光、呼吸、嘴部和身体属于同一意图；
- 结尾状态能连接下一镜；
- 对实际视频的结论带有时间证据。
