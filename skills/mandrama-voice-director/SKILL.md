# 漫剧角色声音导演

声音设计的目标是让角色跨镜、跨集可辨，同时让每句话真正影响交流对象。正式工作必须绑定批准的剧本版本；文字变化要返回剧本负责人处理。

## 先确定声音路线

逐个角色或句子选择：真人录音、已授权音色、普通TTS、视频模型内生对白、画外音、离画声或无对白。路线会影响时长、口型、授权、返修成本和剪辑方式，不应默认全片使用同一种方式。

真人音色模仿、声音克隆、平台上传和付费生成分别要求明确授权。没有权利证明时使用非识别性临时声音，并标记 `TEMP_AUDIO`。

## 角色声音护照

固定角色建立可试听比较的声音护照：

```text
角色ID / 版本
听感年龄与音区
明暗、厚薄、气息和共鸣特征
日常语速与句子节奏
口音、语言和专名读法
压力升高时会改变什么
无论情绪如何都保持什么
禁止的表演习惯
音色来源与使用权
批准试听文件
```

避免只写“高级、磁性、甜美”。同场角色应能通过音区、节奏、气息或发音习惯区分，而不是依赖刻板口音。

## 逐句声音卡

从批准剧本投影每句台词，不重新创作：

```text
句子ID / 说话人 / 原文
声音位置：画内、画外、离画或设备声
说给谁 / 想让对方做什么
承接信息 / 隐含态度
速度、音量和能量走向
关键词重音 / 停顿 / 换气
句尾动作
目标时长
读音说明
口型或剪辑限制
```

一句话可以经历变化，不要从头到尾维持同一强度。指令优先使用可执行策略，例如试探、稳住、催促、掩饰、求证或逼退。

## 时长预演

正式音频前先朗读或制作低成本样音，测量真实时长。把台词、可懂度、必要停顿和对方反应一起放进镜长。

发生超时时按以下顺序处理：

1. 调整自然节奏和停顿；
2. 调整剪辑或镜长；
3. 改变声音位置，例如转为画外音；
4. 返回编剧决定是否改词。

不得擅自删字、吞音、异常加速或截断句尾。

## 试听与正式验收

固定角色先使用同一短文本比较少量有明确差异的候选。记录选择理由和版本，避免每集随机换音色。

正式音频至少进行两种听法：

- 表演听检：人物身份、对象、意图、重音和关系是否成立；
- 技术听检：逐字、读音、噪声、爆音、音量突变、头尾截断和实际时长。

没有听到真实文件时，结果只能是 `AUDIO_NOT_HEARD`。

## 交付物

- 角色声音护照；
- 本集逐句声音卡；
- 专名、数字、多音字和外语读音表；
- 样音比较记录；
- 正式音频问题单与结论。

画内对白完成后，把视频和最终音轨交给 `$mandrama-lipsync-qc`。音色正确不代表嘴部同步已经通过。
