# 漫剧最终文件验收

本 Skill 只对指定的最终候选文件和版本签发结论。任何上游片段、平台状态或编辑工程都不能替代对该文件本身的观看。

## 必要输入

取得最终文件、批准剧本、镜头与时长预演、角色和声音基准、连续性记录、字幕/音乐规则、交付规格、素材权利和发布地区要求。

缺少决定性对照或无法播放完整文件时，结论为 `HOLD` 或 `PARTIAL_CHECK`，不能推测通过。

## 五遍验收

1. **故事遍**：正常速度从头到尾观看，只记录理解、节奏、承诺兑现和情绪结果。
2. **逐镜遍**：检查人物身份、服装、空间、道具、动作物理、表演、摄影和生成伪影。
3. **声音遍**：使用可靠耳机或扬声器检查对白、环境、音效、音乐边界、噪声和头尾。
4. **技术遍**：读取时长、画幅、分辨率、帧率、编码、音轨，并检查开头、四分之一、二分之一、四分之三和结尾附近。
5. **权利遍**：核对人物、声音、音乐、字体、图形、品牌、第三方IP、AI标识和目标平台要求。

所有画内对白镜调用 `$mandrama-lipsync-qc`。人物表演问题可以调用 `$emotion-performance-director` 定位，但最终严重度仍由本 Skill 汇总。

## 检查范围

- 故事：因果是否读得懂，关键对白是否漏、重、错人或改义；
- 连续性：身份、人数、位置、朝向、服装、伤势、道具、场景、时间和光线；
- 表演：刺激与行为变化是否对应，人物是否无故静止或突然失控；
- 动作与摄影：接触、受力、反应、结束状态和摄影运动是否完整；
- 生成缺陷：脸、手、眼、牙、肢体、穿模、闪烁、漂移、换装、黑帧或异常重复；
- 声音：说话人、逐字内容、同步、清晰度、底噪、爆音、音量和环境连续；
- 文字图形：字幕、剧情内文字、拼写、Logo、水印、安全区和裁切；
- 技术权利：文件规格、可播放性、素材授权、必要声明和发布规则。

## 严重度

- `STOP`：文件不可交付、关键剧情缺失、错人说话或权利阻断；
- `FIX`：明显影响观看或可信度，必须返修；
- `POLISH`：不妨碍理解，但存在可感知瑕疵；
- `INFO`：记录性说明，不作为缺陷。

每个问题写明：时间范围、镜头、可复核证据、类别、严重度、影响、责任层、最小返修和复验范围。避免“很假”“节奏不好”这类无法执行的判断。

## 责任与复验

问题只返回真实责任层：剧本、镜头计划、设计资产、表演、声音、视频生成、口型、剪辑、混音、字幕图形、导出或权利。下游遮盖不能把上游错误变成已解决。

返修后至少重看受影响镜头和相邻剪接；若故事时长、主要声音或整体色调发生广泛变化，则重新完整播放。

## 最终结论

- `ACCEPT`：完成所有必要验收，没有 `STOP` 或 `FIX`，其余问题已明确接受；
- `RETURN`：存在可修问题，责任层和复验范围明确；
- `HOLD`：文件、对照、授权或关键检查条件不足；
- `PARTIAL_CHECK`：只完成局部或技术检查。

只有 `ACCEPT` 才能称为交付通过。报告需包含文件哈希或稳定版本标识、实际规格、观看方式、问题单、豁免项、最终结论和下一步。
