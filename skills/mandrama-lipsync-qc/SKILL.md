# 漫剧对白同步质检

本 Skill 只判断“听到的声音是否由正确人物在正确时间自然说出”。剧本质量、声音选角和整体剪辑由各自负责人处理。

## 两类工作

- `SYNC_RISK`：在生成或配口型前识别难以同步的镜头。
- `SYNC_REVIEW`：对实际文件逐镜检查并给出返修责任层。

缺少视频、最终音轨、台词版本或说话人信息时，不做通过结论。

## 生成前风险评估

逐个画内对白镜记录：说话人、逐字台词、计划镜长、声音来源、嘴部可见度、脸部角度、遮挡、头部动作、摄影机运动、同时进行的肢体动作、多人说话顺序和可用剪辑余量。

以下组合通常应降低动作负荷、拆镜或改变声音位置：

- 两人以上快速轮流开口；
- 长句与大幅头部运动同时发生；
- 关键音节期间嘴部被持续遮挡；
- 极端侧脸承担必须读口型的信息；
- 快速运镜同时要求精细嘴形；
- 画内人物与画外声音归属不清。

调整只能改变实现方式，不能私自改变剧情信息。

## 实际检查方法

1. 正常速度完整播放镜头，先判断谁在说、开口是否自然、观感是否成立。
2. 复看开声、关键词、闭唇或爆破音附近、句尾和静默区。
3. 多人镜分别确认说话者开口、倾听者闭口并作合理反应。
4. 可疑片段可以慢放或逐帧定位，但最终严重度以正常速度观看为准。
5. 返修后重新播放该镜及前后剪接。

抽取少量帧只能辅助定位嘴部形变，不能证明同步。

## 问题编码

- `LS-01 NO_ARTICULATION`：有台词但人物没有持续形成说话动作；
- `LS-02 WRONG_OWNER`：声音归到了错误人物；
- `LS-03 GLOBAL_SHIFT`：整句相对画面固定提前或延后；
- `LS-04 KEY_SOUND_MISS`：关键词的嘴形与声音明显冲突；
- `LS-05 IDLE_MOUTH`：静默人物或无声区仍持续动嘴；
- `LS-06 EDGE_ERROR`：开口过早、闭口过晚或句尾被剪掉；
- `LS-07 MOUTH_NOISE`：嘴唇、牙齿或下颌出现高频抖动；
- `LS-08 FACE_DAMAGE`：同步期间嘴部或人物身份结构损坏；
- `LS-09 HIDDEN_EVIDENCE`：嘴部不可观察，无法完成要求的验收。

## 最小返修原则

先判断根因属于哪一层：台词与镜长、声音文件、时间线、视频生成、动作过载、镜头遮挡或人物资产。

- 固定时间偏移优先在时间线调整；
- 台词无法自然说完，返回声音预演或镜头时长；
- 错人开口、长期不动嘴或严重嘴部结构问题，返回视频生成；
- 动作竞争导致口型失控，减少动作或拆镜；
- 嘴部不可见但剧情不要求观众确认口型，可以标记 `SYNC_NOT_REQUIRED`，不能标记已验证同步。

每次返修记录改变了什么。达到项目尝试上限后停止并保留失败版本、时间点和平台回执。

## 结果格式

```text
文件与版本：
镜头 / 时间范围：
说话人 / 句子ID：
正常速度观察：
问题编码与严重度：
根因责任层：
最小返修：
复验范围与结果：
结论：SYNC_OK / SYNC_FIX / SYNC_HOLD / SYNC_NOT_REQUIRED
```

错人发声、关键对白人物不开口、明显整句错位、无声人物持续张嘴、句尾截断和严重嘴部变形均不能判定 `SYNC_OK`。
